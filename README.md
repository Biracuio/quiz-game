# 🎮 Quiz Game

![Unity](https://img.shields.io/badge/Unity-000000?style=flat-square&logo=unity&logoColor=white)
![C%23](https://img.shields.io/badge/C%23-68217A?style=flat-square&logo=csharp&logoColor=white)

Projeto desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas**, utilizando **Unity** e **C#**, com o objetivo de criar um jogo de perguntas e respostas que desafia os conhecimentos do jogador de forma dinâmica e interativa.

O jogo apresenta perguntas sorteadas aleatoriamente, controle de tempo, sistema de pontuação e telas de navegação desenvolvidas na Unity.

## ✨ Funcionalidades

- Menu inicial
- Perguntas de múltipla escolha
- Seleção aleatória das perguntas
- Cronômetro durante a partida
- Sistema de pontuação
- Tela de Game Over
- Interface gráfica desenvolvida na Unity

---

## 🛠 Tecnologias utilizadas

- Unity
- C#
- Visual Studio
- Programação Orientada a Objetos (POO)

---

## 📚 Conceitos aplicados

Durante o desenvolvimento foram utilizados conceitos como:

- Programação Orientada a Objetos;
- Organização de scripts;
- Gerenciamento de cenas;
- Manipulação de interface gráfica (UI);
- Controle de estados do jogo;
- Estruturas condicionais e de repetição;
- Controle de tempo;
- Randomização de perguntas;
- Lógica de programação.

---

## 💡 Aprendizados

Este projeto proporcionou uma experiência prática no desenvolvimento de aplicações utilizando a Unity.

Ao longo do desenvolvimento foi possível compreender a importância da organização do código, da separação de responsabilidades entre scripts, da experiência do usuário e da realização de testes para garantir o correto funcionamento da aplicação.

Além disso, o projeto contribuiu para o aperfeiçoamento da lógica de programação e do desenvolvimento orientado a objetos utilizando C#.
